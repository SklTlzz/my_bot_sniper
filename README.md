# TG-Бот для сканирования крипто рынка

**[Запустить бота в Telegram](https://t.me/skltlzz_gem_bot)**

Асинхронный Telegram-бот для агрегации рыночных данных с 9 топовых криптобирж через REST API и WebSocket. 

Главная цель бота — в реальном времени отслеживать манипуляции на спотовом рынке актива (например, депозиты китов на биржи после пампа) и моментально присылать алерты о критических изменениях, чтобы успеть принять торговое решение.

## Стек технологий
- **Python** — основная логика
- **asyncio & aiohttp** — асинхронный сбор данных (REST/WebSocket)
- **aiogram** — интерфейс и обработка взаимодействия с Telegram API
- **aiosqlite** — база данных для хранения пользователей и их настроек
- **numpy** — быстрые математические вычисления для поиска отклонений

## Ключевой функционал
- **Мульти-биржевой агрегатор:** Одновременный сбор и обработка потока данных с 9 криптобирж
- **Детектор плотностей:** Сканирование стаканов на наличие аномально больших лимитных заявок, сдерживающих или толкающих цену
- **Отслеживание аномалий:** Алгоритм фиксирует резкие ценовые сквизы и нетипичные всплески проторгованных объемов
- **Real-time уведомления:** Мгновенная отправка алертов прямо в Telegram при срабатывании любого из триггеров
